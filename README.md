# CyberNotes — Kali Linux & Cybersecurity

A beginner-friendly static website for sharing original Linux and cybersecurity notes.

## Files
- `index.html` — website structure
- `style.css` — responsive styling
- `script.js` — theme toggle
- `notes/` — Markdown learning notes
- `assets/` — place future screenshots/illustrations here

## GitHub Pages
Upload this folder to a GitHub repository, then enable GitHub Pages from the repository settings. The site is plain HTML/CSS/JS, so no build step is required.

## Content policy for the project
Keep examples educational and authorized: local VMs, CTFs, intentionally vulnerable applications, or systems you have permission to test.
